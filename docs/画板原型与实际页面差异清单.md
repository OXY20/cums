# CUMS 画板原型 vs 实际项目页面差异清单

> 对比对象：
> - 画板原型：`draw2code/课堂文件管理.excalidraw.json`（198 个元素，6 个学生端页面）
> - 实际项目页面：`static/index.html`（学生端）、`static/admin.html`（管理端）、后端 `src/handlers.rs` / `src/main.rs`
> - 日期：2026-08-25
> - 用途：作为在画板补齐页面、生成前端页面、或对外对接设计软件的差异基线。

---

## 一、结构性差异（整体）

| # | 对比维度 | 画板原型 | 实际项目 | 严重度 |
|---|----------|----------|----------|:---:|
| 1 | 覆盖范围 | 仅学生端 6 页 | 学生端 + 完整管理后台（8 页） | 🔴 高 |
| 2 | 页面组织 | 6 个独立 frame 平铺 | 学生端是 SPA（单页切换 + 隐藏显示）；管理端是侧边栏 + Tab | 🟡 中 |
| 3 | 弹窗形态 | 登录画成独立整页 | 登录/改密/附件均为**模态框弹窗** | 🔴 高 |
| 4 | 用户菜单 | 无 | 登录后有**用户下拉菜单** | 🔴 高 |
| 5 | 登录态切换 | 首页同时显示「我的课程」+「登录」 | 未登录 `[全部课程][登录]`；登录后 `[全部课程][我的课程][用户▼]` | 🔴 高 |
| 6 | 交互能力 | 静态（点不了） | 可点击、可跳转、可提交、可预览 | 🟡 中 |

## 二、学生端逐页差异

### 1. 首页
| 画板 | 实际 | 严重度 |
|------|------|:---:|
| 导航「全部课程+我的课程+登录」并存 | 登录/未登录二选一显示 | 🔴 |
| 横幅左侧静态封面框 | 多课程**自动轮播**（4 秒切换 + 圆点 + 点击进入） | 🟡 |
| 右侧卡片仅「进入课程」 | 另有「**提交作业**」按钮（登录后显示） | 🟡 |
| 状态标签写死「已提交」 | 动态 4 态：已完成/需修改/待评审/待提交 | 🟡 |
| 3 张卡片无分页 | 每页 9 张 + 上/下一页 + 页码 | 🟢 低 |

### 2. 课程主页
| 画板 | 实际 | 严重度 |
|------|------|:---:|
| 导航无返回 | 有返回首页入口 | 🟡 |
| 课时行只有图标+名称+标签 | 每行还有**课时简介** + 右箭头 | 🟡 |
| 仅 4 条课时 | 全部课时（本课程 8 条） | 🟢 低 |
| 提交按钮常显 | 仅登录后显示 | 🟡 |

### 3. 课时详情页
| 画板 | 实际 | 严重度 |
|------|------|:---:|
| 「下载附件」按钮 | 点击弹**附件弹窗**（列表+下载+预览+一键打包 ZIP） | 🔴 弹窗缺失 |
| 目录文案简化「1 表格基本概念」 | 全称「第1课时 · 表格基本概念」 | 🟢 低 |
| 目录静态 | 点击目录项跳转课时 | 🟡 |
| 只展示标题/段落/图片/视频 | Markdown 还支持代码/列表/链接/表格 | 🟢 低 |
| 提交按钮常显 | 仅登录后显示 | 🟡 |
| 无响应式 | 窄屏目录折叠为右下角悬浮按钮 + 滑出面板 | 🟢 低 |

### 4. 作业提交页
| 画板 | 实际 | 严重度 |
|------|------|:---:|
| 评审只画「通过」一种 | 三种：通过(绿)/退回(红)/待评审(蓝) | 🟡 |
| 预览区仅文字 | 选择文件后**真预览**：图片/PDF 内嵌/视频/文档图标 | 🟡 |
| 无 | **已上传文件抽屉**（按钮+列表，默认收起） | 🔴 缺失 |
| 无 | 未登录跳登录；首次改密前提交被拦 403 | 🟢 低 |
| 有「截止：2026-01-30 23:59」 | **实际代码无截止时间字段**（需求文档有，未实现） | 🟡 画板超前 |
| 表单显示已选文件 | 默认「未选择文件」态 | 🟢 低 |

### 5. 我的课程
| 画板 | 实际 | 严重度 |
|------|------|:---:|
| 单卡片内三色分组列表 | **多张课程卡片**（每门课一张：进入课程/专业/课时/进度/统计） | 🔴 结构不同 |
| 有「重新提交」按钮 | 卡片仅「进入课程」 | 🟡 |
| 只展示一门课 | 显示该班所有课程 | 🟢 低 |
| 无登录态 | 未登录显示「请先登录」 | 🟢 低 |
| 已完成只列 2 条 | 底部「展开更多」折叠全部 | 🟢 低 |

### 6. 个人中心 / 登录
| 画板 | 实际 | 严重度 |
|------|------|:---:|
| 登录画成独立整页 | 模态框弹窗 | 🔴 |
| 只有登录表单 | 另有**修改密码弹窗**（旧/新/确认） | 🔴 缺失 |
| 无 | **用户下拉菜单**（姓名班级/当前课程/改密/退出） | 🔴 缺失 |
| 无 | 首次登录强制改密提示 | 🟡 |
| 无 | 退出登录动作 | 🟡 |

## 三、管理端（画板完全缺失，8 页）

| 页面 | 功能要点 | 画板 |
|------|----------|:---:|
| 登录页 | 密码认证、回车登录 | ❌ |
| 仪表盘 | 统计卡片（文件/大小/科目/班级/作业）、科目统计表、最近上传、实时时钟 | ❌ |
| 科目管理 | 增删改、按行导入、课程元数据、模板上传/删除、课时 Markdown 编辑 + 媒体上传 | ❌ |
| 名单管理 | XLSX 模板下载/导入、CSV/TSV/JSON 导入、重置密码、删除、密码状态徽标 | ❌ |
| 文件管理 | 科目/班级/作业三级筛选、删除 | ❌ |
| 提交情况 | 已/未提交统计、逐学生评审（通过/退回 + 批注） | ❌ |
| 设置 | 当前课程设置、修改管理员密码 | ❌ |
| 操作日志 | 时间/动作/详情列表 | ❌ |

> 管理端还含主题切换（深色/日间）、侧栏折叠等 UI 特性，画板均未体现。

## 五、结论

1. **最大缺口**：管理端 8 个页面完全未画。
2. **学生端主要差异**：弹窗（附件/改密/用户菜单）、已上传文件抽屉、登录态切换逻辑、我的课程页结构。
3. **画板超前项**：截止时间字段（需后端支持后才算真实）。
4. **下一步**：在画板补齐管理端 8 页 + 修正学生端差异 → 调用 draw2code_generate 生成真实 HTML 页面。
