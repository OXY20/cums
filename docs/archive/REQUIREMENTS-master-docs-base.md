## 一、运行环境

### 1.1 运行时环境

| 项目 | 说明 |
|------|------|
| 系统平台 | Windows / Linux / macOS（跨平台，单一可执行文件部署） |
| 运行方式 | 预编译二进制直接运行，或用 Go 源码编译运行 |
| Go 版本 | 文档标注 Go 1.18+；实际 `go.mod` 为 `go 1.25`（用户实际使用 Go 1.25.0，配置已验证正确） |
| 依赖 | 纯 Go 标准库，零第三方依赖；前端为原生 HTML/CSS/JS 单页应用 |
| 网络环境 | 局域网（机房内部），监听 `0.0.0.0`，支持学生机通过局域网 IP 访问 |
| 默认端口 | `:3000`（可在 `config.json` 中通过 `server_addr` 修改） |
| 存储 | `uploads/科目/班级/作业/` 目录；日志写入 `logs/cums.log` |

### 1.2 部署方式

参考 `docs/DEPLOYMENT.md`，支持以下部署形态：

- **方式一**：直接运行可执行文件（开发/测试）
- **方式二**：Docker 容器化部署（挂载 `uploads/` 与 `config.json`）
- **方式三**：Systemd 服务（Linux）
- **方式四**：Nginx 反向代理 + HTTPS
- **CI 发布**：打 `v*` tag 自动触发三平台（Windows/Linux/macOS）交叉编译并发布 Release

### 1.3 配置环境（`config.json`）

- 当前实际配置：2 个科目（人工智能、文字处理），4 个班级（25体育、25食品、25幼托、25计应），文字处理含 4 个作业（WT16/WT19/WT21/WPS21）
- 管理后台默认关闭，需 `admin_enabled: true` 并设置明文 `admin_password` 后启用
- 修改配置后需重启程序生效（管理后台在线修改除外，实时生效并同步配置文件）

## 二、使用对象

| 角色 | 使用方式 | 权限与功能 |
|------|---------|-----------|
| **学生** | 浏览器访问学生端首页（`/`） | 选择班级、输入学号和姓名登录；按科目到班级到作业级联选择后上传文件；无需密码认证 |
| **教师/管理员** | 浏览器访问管理后台（`/admin`） | 密码登录（24 小时有效令牌）；在线增删改科目、班级、作业配置，实时生效并同步 `config.json`；查看上传文件目录与日志 |
| **运维/部署人员** | 控制台 + 配置文件 | 编辑 `config.json`、管理 `uploads/` 与 `logs/`、部署服务 |
| **开发者** | Git + Go 工具链 | 在 `develop` / 功能分支开发、按 Conventional Commits 提交、构建跨平台产物 |

**典型场景**：学校机房局域网内，某教师带多个班级（如 25 级各班）开设多门科目，学生课上提交作业文件，教师课后从目录或管理后台归档查看。

## 三、需求分析

### 3.1 功能需求（当前已实现）

**学生端**

- 简洁免密登录：班级下拉选择 + 学号 + 姓名（班级从配置自动收集并校验）
- 级联选择：科目到班级到作业（依据配置过滤，登录后只显示含当前班级的科目）
- 文件上传：multipart 上传，扩展名白名单校验（文档、图片、压缩包、代码类）
- 自动命名与存储：`{作业名}_{学号}_{姓名}_{时间戳}.{扩展名}`，存储于 `uploads/科目/班级/作业/`
- 版本与更新日志展示（`/api/v1/version`、`/api/v1/changelog`，日志经 `go:embed` 内嵌）

**管理端**

- Web 管理后台：在线管理科目、班级、作业，配置实时生效无需重启
- 管理员认证：密码登录 + 令牌机制（内存存储、24 小时过期、每小时自动清理）

**系统**

- 实时日志：控制台 + `logs/cums.log` 双写，记录时间、班级、学号、姓名、科目、作业、IP、主机名（反向 DNS）
- 自动初始化：首次运行自动创建 `uploads/`、`logs/` 目录及配置结构
- 跨平台构建与自动发布（CI 三平台产物）

**安全（v2.0 批量修复）**

- 路径遍历防护：`sanitizeFilename` 严格白名单过滤（字母、数字、下划线、连字符、中文）
- 文件类型白名单；前后端 XSS 转义（`escapeHtml`）
- 管理员令牌 `crypto/rand` 随机生成；统一 HTTP 状态码；令牌定时清理

### 3.2 待办与规划需求（文档中的 TODO）

**已列入计划（未实装）**

1. 作业模板下载功能：学生下载模板、完成作业、提交
2. 作业说明功能：为作业添加说明文字与图片，学生端展示作业要求和说明
3. 配置结构扩展（规划中）：`homeworks` 从字符串升级为对象（含 `name`、`description`、`template`、`images`）

**待修复项**

参考 `docs/待修复问题清单.md`，共 15 项已完成 14 项，剩余 1 项：

- P3：缺少统一中间件封装（请求日志中间件、panic 恢复、CORS），标注为可延后

**改进建议（PROJECT_REVIEW / ISSUES）**

- 短期：补充单元测试（`main_test.go`）、健康检查接口（`/health`）、配置加载验证
- 中期：日志级别与轮转、文件大小限制、错误码统一定义、前端加载状态
- 长期：用户身份验证、文件预览、统计报表、批量下载

### 3.3 非功能需求

- **易用性**：学生零学习成本（三步选择后上传）、界面简洁
- **可维护性**：单文件后端（约 776 行），结构分区清晰，全中文注释
- **安全性**：面向可信内网，管理员密码明文存储（文档明确提示仅限可信网络使用）
- **可扩展性**：配置结构支持无限科目、班级、作业；规划中的对象化作业结构为扩展预留
- **跨平台**：三平台行为一致
