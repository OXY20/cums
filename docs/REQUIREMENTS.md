# CUMS 课程中心 — 需求功能文档

> 版本：v2.0（最终定稿）  
> 日期：2026-01-21  
> 基于现有 CUMS v2.3.3 系统，将学生端从"登录后上传文件"改造为"类慕课课程中心 + 作业提交"的双模前端。

---

## 一、项目背景

### 1.1 现有系统概述

CUMS（课堂文件上传管理系统）当前是一个面向机房场景的文件提交系统：

- **学生端**：登录 → 查看科目/作业/课时 → 下载模板 → 上传文件。所有功能均需登录。
- **管理端**：管理学生名单、科目配置、课时 Markdown 内容、课时媒体文件、模板文件、查看提交记录与统计。
- **课时系统**：已有课时 Markdown 正文存储（`lessons/`）、课时媒体上传（`lesson_media/`）、课时简介（`description`），前端支持 Markdown 渲染（标题、粗体、代码、图片、视频、链接）。

### 1.2 改造目标

将学生端改造为一个**公开可访问的课程中心**，参考中国大学MOOC、学堂在线等慕课平台的交互模式，让学生无需登录即可浏览课程信息、查看课时内容；仅在提交作业文件时才需要登录认证。

---

## 二、用户角色

| 角色 | 说明 |
|------|------|
| **访客（未登录用户）** | 可浏览所有课程主页、查看课时详情、下载附件，不可提交作业 |
| **学生（已登录用户）** | 除访客权限外，可查看自己班级的课程进度、提交作业文件 |
| **管理员（后台）** | 管理课程、课时、媒体、学生名单、查看提交记录与统计 |

---

## 三、设计原则

- **简洁为主**：少装饰，低资源占用，无花哨 CSS 动画
- **图标**：使用 SVG icon，不使用 emoji
- **响应式**：桌面端优先，平板支持，窄屏时侧栏折叠为浮动图标
- **导航逻辑**：未登录仅显示 `[登录]`；已登录显示 `[全部课程] [我的课程] [用户]`

## 五、三色标记体系
