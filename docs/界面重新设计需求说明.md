# CUMS 界面重新设计需求说明

> 用途：供在其他设计软件（如 Pixso、Figma、墨刀等）中重新设计 CUMS 界面时参考。
> 依据：当前 CUMS v2.4.0 实际代码（`static/index.html` 学生端、`static/admin.html` 管理端、`src/handlers.rs` 后端 API）。
> 说明：以下列出系统全部功能、所有页面及其各自拥有的不同功能点，可作为界面重设计的完整功能基线。

---

## 一、系统整体概述

**CUMS（课堂文件上传管理系统 / 课程中心）** 是一个面向机房教学场景的 Web 应用，包含两个独立界面：

| 界面 | 访问地址 | 面向人群 | 设计风格现状 |
|------|----------|----------|--------------|
| 学生端（课程中心） | `/` | 访客、学生 | 浅色、简洁、蓝色主色（#1890ff），单页应用多视图切换 |
| 管理端（管理后台） | `/admin` | 管理员 | 深色玻璃拟态 + 可切换日间模式，左侧边栏布局 |

**角色与权限：**

| 角色 | 权限 |
|------|------|
| 访客（未登录） | 浏览全部课程、查看课时详情、下载课时附件；不能提交作业、没有个人进度 |
| 学生（已登录） | 在访客权限基础上，可查看"我的课程"与个人学习进度、提交作业、查看教师评审结果、修改密码 |
| 管理员 | 全部管理功能（科目/名单/课时/模板/文件/统计/评审/日志/设置） |

**导航逻辑差异（核心状态切换）：**
- 未登录：顶部导航只显示 `[全部课程]` + `[登录]` 按钮；隐藏"我的课程"入口和提交按钮。
- 已登录：顶部导航显示 `[全部课程] [我的课程] [用户姓名 ▼]`；各处出现"提交作业"入口。

## 二、学生端页面及各页面功能清单

学生端是**单页应用（SPA）**，通过顶部导航/点击在不同视图间切换，共 5 个主要页面视图 + 2 个弹窗 + 1 个下拉菜单。

### 页面 1：首页（全部课程视图）

| 区域 | 功能说明 |
|------|----------|
| 顶部导航栏 | 左侧：书本图标 + "CUMS 课程中心"（点击回首页）；右侧：`[全部课程]` `[我的课程]`（仅登录后显示）`[登录]`按钮 / `[用户姓名 ▼]`用户菜单 |
| 当前进行中横幅 | 左侧：课程封面**轮播**（16:9，自动每 4 秒切换，带圆点指示器，可点击进入课程）；右侧：当前进行中课程卡片，含"进行中"红色角标、封面、课程名、班级、简介、学习进度（`完成/总课时`）、三色状态标签、`[进入课程]`和`[提交作业]`（仅登录显示）按钮 |
| 课程筛选栏 | 两个下拉筛选：`[全部专业 ▾]`、`[全部班级 ▾]`，选项从课程元数据动态生成 |
| 课程卡片网格 | 每张卡片：封面图（无封面时显示渐变+课程名）、课程名称、所属专业、`共 N 课时`；点击卡片进入课程主页 |
| 分页 | 每页 9 门课程，上一页/下一页 + 页码 + `共 N 门课程` 统计 |
| 页脚 | `CUMS v2.4.0` 版本号 |

**本页独有功能：** 课程封面轮播、专业/班级筛选、课程卡片分页。

### 页面 2：课程主页

| 区域 | 功能说明 |
|------|----------|
| 左侧进度面板 | `我的学习进度`标题 + 所属班级；进度条（已完成百分比）；`已完成 X/N 课时`；三个彩色统计：`通过`(绿)/`待评审`(蓝)/`需修改`(红)；提交作业快捷入口 |
| 右侧课程信息卡 | 课程封面大图、课程名称、专业、课程简介文字 |
| 全部课时列表 | 每行：状态圆图标 + 课时名 + 课时简介（单行省略）+ 状态标签 + 右箭头 |
| 三色状态标记 | 绿`✓ 已通过`（已完成）、红`! 需修改`（存在问题）、蓝`· 待评审`（提交未审）、灰（未提交无标签） |

**本页独有功能：** 学习进度条与三色统计、课时状态标记体系（与"我的课程"页共用三色体系）。

### 页面 3：课时详情页

| 区域 | 功能说明 |
|------|----------|
| 左侧正文区 | 课时标题；课时简介（浅蓝底左侧蓝边提示条）；Markdown 渲染正文，支持：标题、粗体/斜体、行内/块级代码、有序/无序列表、图片、视频（`@[视频]`语法）、链接、段落 |
| 右侧目录栏 | `课时目录`标题 + 目录列表（当前课时红色高亮加粗；超 8 条显示`展开更多 N 课时`/`收起`，点击目录项跳转课时） |
| 操作按钮 | `[下载附件]`按钮（打开附件弹窗）、`[提交作业]`按钮（仅登录显示，跳转提交页并预选当前课时） |
| 附件弹窗（本页触发） | 弹窗标题"本课时附件"；每个附件一行：名称 + 大小 + `[下载]`按钮；底部`一键打包下载全部附件`按钮；无附件时显示"本课时暂无附件" |
| 响应式 | 窄屏时右侧目录折叠为右下角悬浮圆形按钮 + 右侧滑出面板 |

**本页独有功能：** Markdown 课时正文渲染、课时目录（展开/收起/当前高亮）、课时附件列表与打包下载。

### 页面 4：我的课程（仅登录可见）

| 区域 | 功能说明 |
|------|----------|
| 顶部说明 | `我的课程 · 25计应`（当前班级） |
| 课程卡片列表 | 每个卡片：课程名 + `[进入课程]`按钮、专业 + `共 N 课时`、进度条、`已完成 X/N 课时`、统计行`通过 X · 待评审 X · 需修改 X` |
| 空状态 | 未登录时显示"请先登录后查看我的课程进度"；无课时显示"当前班级暂无课程" |

**本页独有功能：** 按学生所在班级聚合课程与个人进度。

### 页面 5：作业提交页

| 区域 | 功能说明 |
|------|----------|
| 顶部选择区 | `作业提交`标题 + 三级下拉：`[课程 ▾]` `[作业 ▾]` `[课时 ▾]`（仅登录显示本班课程） |
| 教师评审结果区 | 按当前作业显示评审卡片：绿（`[通过] 教师已评审`+批注+评审时间）/ 红（`[存在问题] 需要重新提交`）/ 蓝（`[待评审] 作业已提交，等待教师审核`+提交时间） |
| 文件预览区 | 已选择文件后预览：图片直接显示、PDF 内嵌预览、视频在线播放、其他文件显示文件图标 + 名称 + 大小；未选择时提示"请选择文件后在此处预览" |
| 已上传文件抽屉 | `[已上传文件]`按钮（有历史提交时显示），点开显示已提交文件列表（文件名 + 大小），默认收起 |
| 文件选择与提交 | `[选择文件]`按钮 + 文件名/大小提示；`[确认提交]`绿色按钮；格式提示：`支持：docx/xlsx/pptx/pdf/zip/rar/jpg/png/mp4，最大32MB` |
| 右侧作业信息卡 | `作业信息`标题 + 名称、说明、`[下载模板]`链接列表（作业配置了模板时显示） |

**本页独有功能：** 三级下拉选择、文件预览（多类型）、已上传文件抽屉、提交上传（需登录且已完成首次改密）。

### 弹窗 1：登录模态框
- 书本/锁图标 + `学生登录`标题
- 表单：姓名输入框、密码输入框（回车可提交）
- `登 录`按钮（全宽）
- 底部提示：`默认密码 000000，首次登录后请及时修改`
- 右上角 `X` 关闭

**本弹窗独有功能：** 姓名+密码登录、首次登录强制改密提示。

### 弹窗 2：修改密码模态框
- 锁图标 + `修改密码`标题
- 表单：旧密码、新密码（至少6位）、确认新密码
- `确认修改`按钮（全宽）

**本弹窗独有功能：** 修改学生个人密码（需登录令牌）。

### 下拉菜单：用户菜单
- 头部：姓名 + `学号 · 班级`
- 当前课程信息块：当前进行中课程 + 课时 + `未提交 [提交作业]`（部分情况）
- `修改密码`、`退出登录`两个菜单项
- 点击页面其他区域自动关闭

## 三、管理端页面及各页面功能清单

管理端是**侧边栏 + 多 Tab 内容区**布局：左侧固定侧边栏（品牌名 + 7 个菜单项 + 底部工具），右侧头部（标题 + 实时时钟）+ 主内容区。支持**深色/日间模式切换**、**侧栏折叠/收起**、窄屏时侧栏变抽屉。

### 页面 A：登录页
- 锁图标 Logo + `CUMS 管理后台` + `请输入管理员密码以继续`
- 密码输入框（回车登录）+ `登 录`按钮
- 错误提示信息条

**本页独有功能：** 管理员密码登录（`admin_enabled` 关闭时不可用）。

### 页面 B：仪表盘
| 区域 | 功能说明 |
|------|----------|
| 系统概览 | 5 张统计卡片：总文件数、总大小、科目数、班级数、作业数 |
| 科目统计 | 表格：科目 / 文件数 / 总大小 / 班级数 / 作业数 |
| 最近上传 | 列表：文件名 + 大小 + 修改时间 |
| 侧边栏 | 菜单：仪表盘、科目管理、名单管理、文件管理、提交情况、设置、操作日志；底部：`访问首页`、`日间模式`切换、`退出登录` |

**本页独有功能：** 全局统计展示、实时时钟。

### 页面 C：科目管理
| 区域 | 功能说明 |
|------|----------|
| 科目卡片列表 | 每个科目：图标 + 科目名 + 操作按钮（`编辑信息` `模板` `删除科目`）；两块内容：`班级`标签列表（可逐个 ×删除、`+ 添加`）、`作业`标签列表（可 ×删除、每个作业下方列出`课时: xxx`按钮、`+ 课时`、`+ 添加作业`） |
| 按行导入科目 | 文本域说明`每行格式：科目,班级,作业,描述`，也支持 JSON 数组；`[导入科目]`按钮 |
| 添加科目 | 输入科目名称 + `[添加科目]`按钮 |
| 编辑课程信息弹窗 | 课程简介、封面图片 URL、专业三个字段 + 保存 |
| 模板管理弹窗 | 先选作业（快速选择按钮），然后：上传模板文件 + `[上传]`、模板文件列表（名称 + ×删除） |
| 课时编辑弹窗 | 课时简介文本域；Markdown 正文文本域；`[上传课时媒体]`选择文件 + `[上传并插入链接]`按钮（图片插 `![...](url)`、视频插 `@[视频](url)`、其他插 `[下载...](url)`）；`[保存课时]`按钮 |

**本页独有功能：** 科目/班级/作业/课时的增删改、批量导入、课程元数据编辑、模板上传删除、课时 Markdown 编辑与媒体上传。

### 页面 D：名单管理
| 区域 | 功能说明 |
|------|----------|
| 工具条 | `[下载 XLSX 模板]`、`[选择 XLSX 导入]`（accept .xlsx）、导入结果消息条 |
| 名单输入 | 文本域（占位示例：`学号,姓名,班级`，支持 CSV/TSV/JSON）；`[导入名单]` + `[刷新名单]` |
| 学生表格 | 列：学号、姓名、班级、密码状态（`待修改密码`黄标 / `已设置`绿标）、操作（`重置密码` `删除`） |
| 空状态 | "暂无学生名单" |

**本页独有功能：** 名单 XLSX 模板下载、XLSX 导入、CSV/TSV/JSON 粘贴导入、重置密码、删除学生。

### 页面 E：文件管理
| 区域 | 功能说明 |
|------|----------|
| 筛选栏 | 科目 / 班级 / 作业三级下拉（联动）+ `[刷新]`按钮 |
| 文件表格 | 列：文件名、大小、修改时间、路径、操作（`删除`） |
| 空状态 | "暂无文件" |

**本页独有功能：** 学生上传文件的分类浏览与删除。

### 页面 F：提交情况
| 区域 | 功能说明 |
|------|----------|
| 筛选栏 | 科目 / 班级 / 作业三级下拉（联动），全部选择后加载 |
| 提交概览 | 当前作业名 + `科目 / 班级`；左右两块：`已提交 (N)` 绿色标签列表、`未提交 (N)` 红色描边标签列表 |
| 作业评审区 | 每个学生一行：姓名（学号）+ 评审结果下拉（未评审/通过/退回）+ 批注输入框 + `[评审]`按钮 |

**本页独有功能：** 提交/未提交统计、逐学生作业评审（通过/退回 + 批注，评审结果反馈到学生端三色状态）。

### 页面 G：设置
| 区域 | 功能说明 |
|------|----------|
| 当前课程设置 | `当前进行中科目`下拉 + `当前进行中班级`下拉（联动）+ `[保存当前课程设置]`；结果消息条 |
| 系统设置 | 修改管理员密码表单：当前密码、新密码（至少4位）、确认新密码 + `[修改密码]`（成功后强制重新登录） |

**本页独有功能：** 设置首页"当前进行中"横幅课程与班级、修改管理员密码。

### 页面 H：操作日志
- `[刷新]`按钮
- 日志列表：时间 / 动作 / 详情（时间戳 + 操作类型 + 描述）
- 空状态："暂无操作日志"

**本页独有功能：** 查看管理员与学生的操作留痕。

## 五、关键交互与状态（重设计时需保留）

1. **三色状态体系**（学生端课程/课时/横幅/提交页共用）：
   - 绿 = 已完成/通过；红 = 存在问题/需修改/退回；蓝 = 待评审；灰 = 未提交。
2. **登录态切换**：登录后导航项、提交按钮、"我的课程"入口立即出现；退出后恢复访客态。
3. **首次改密强制**：登录返回 `force_password_change=true` 时必须先改密，未改密不能提交作业（服务端返回 403）。
4. **课时目录规则**：默认显示 8 条，超出显示"展开更多 N 课时"，当前课时红色高亮。
5. **响应式**：桌面优先；窄屏时课时目录变悬浮按钮 + 滑出面板；管理端侧栏变抽屉。
6. **文件格式白名单**：学生作业 docx/xlsx/pptx/pdf/zip/rar/jpg/png/mp4（最大 32MB）；课时媒体含图片/音视频/Office/PDF/压缩包（最大 64MB）。
7. **管理端主题**：深色默认 + 日间模式切换（localStorage 记忆）、侧栏折叠记忆。
8. **Markdown 安全**：前端渲染仅允许 http/https/相对路径链接，禁止 `javascript:` 等危险协议。

## 六、重设计交付建议

- 可分别设计两套风格：学生端（面向学生、清爽、蓝色系、课程内容浏览为主）与管理端（面向教师、信息密度高、仪表盘式）。
- 所有页面均需包含空状态、加载中、错误提示的占位设计。
- 保留本文第四节"功能差异速查表"中每个页面独有的交互元素，勿在重设计时遗漏或合并。
