# 变量与数据类型

## 一、基本数据类型

| 类型 | 关键字 | 大小 | 范围 |
|------|--------|------|------|
| 整型 | int | 4字节 | -2^31 ~ 2^31-1 |
| 字符型 | char | 1字节 | -128 ~ 127 |
| 浮点型 | float | 4字节 | 约7位精度 |
| 双精度 | double | 8字节 | 约15位精度 |

## 二、变量声明

```c
int age = 18;
float score = 95.5;
char grade = 'A';
double pi = 3.1415926535;
```

## 三、命名规则

- 由字母、数字和下划线组成
- 不能以数字开头
- 区分大小写
- 不能使用关键字
