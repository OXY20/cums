# 认识C语言

## 一、C语言简介

C语言是由Dennis Ritchie于1972年在贝尔实验室开发的一种通用编程语言。

### C语言的特点
- **高效性**：接近汇编语言的执行效率
- **可移植性**：代码可以在不同平台上编译运行
- **灵活性**：支持多种编程范式
- **简洁性**：语法简洁，关键字少

## 二、开发环境搭建

### Windows环境
1. 下载并安装MinGW或Visual Studio
2. 配置环境变量
3. 安装代码编辑器（如VS Code）

### 第一个C程序

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## 三、程序结构

一个C程序的基本结构：
- 预处理指令（#include）
- 主函数（main）
- 语句和表达式
- 注释

1. 搭建C语言开发环境
