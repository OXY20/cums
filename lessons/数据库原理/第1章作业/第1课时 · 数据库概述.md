# 数据库概述

## 一、什么是数据库

数据库（Database）是按照数据结构来组织、存储和管理数据的仓库。

### 数据库的发展
1. **人工管理阶段**（20世纪50年代前）
2. **文件系统阶段**（20世纪50-60年代）
3. **数据库系统阶段**（20世纪60年代至今）

## 二、常见数据库系统

### 关系型数据库
- MySQL
- PostgreSQL
- SQL Server
- Oracle

### 非关系型数据库
- MongoDB
- Redis
- Cassandra

## 三、数据库的基本概念

- **数据（Data）**：描述事物的符号记录
- **数据库（DB）**：长期存储在计算机内的有组织的数据集合
- **数据库管理系统（DBMS）**：管理数据库的软件
- **数据库系统（DBS）**：数据库+DBMS+应用程序+用户
